1. CSS Transitions

Para animar UN cambio de estado (hover, click, clase agregada). No sirve para loops ni secuencias con varios pasos — para eso están los @keyframes (sección 2).

hover con transition

/* Pasa el mouse por encima del cuadro */
.caja {
  transition: transform 0.3s ease, background 0.3s ease;
  /* formato: propiedad | duración | timing-function | delay(opcional) */
}
.caja:hover {
  transform: scale(1.3);
}

Propiedades clave de transition

PropiedadQué hace
transition-propertyQué propiedad(es) animar (o all)
transition-durationCuánto dura, ej. 0.3s
transition-timing-functionCurva de aceleración (ver sección 4)
transition-delayEspera antes de iniciar

2. @keyframes — lo básico

Para secuencias con varios pasos, loops infinitos, o animaciones que corren solas sin esperar un evento del usuario.

Anatomía de un @keyframes

/* 1. Defines los "fotogramas clave" con porcentajes o from/to */
@keyframes mi-animacion {
  0%   { opacity: 0; transform: translateY(20px); }
  50%  { opacity: 0.5; }
  100% { opacity: 1; transform: translateY(0); }
}

/* 2. La aplicas a un elemento con la propiedad "animation" */
.elemento {
  animation: mi-animacion 1s ease-in-out;
  /* nombre | duración | timing-function */
}

3. Todas las propiedades animation-*

El shorthand animation es la combinación de estas 8 propiedades, en este orden (todas opcionales excepto nombre y duración).

PropiedadValores comunesQué controla
animation-namenombre del @keyframesCuál animación usar
animation-duration2s, 500msCuánto dura UN ciclo
animation-timing-functionease, linear, cubic-bezier()Curva de velocidad
animation-delay0.5sEspera antes de empezar
animation-iteration-count1, 3, infiniteCuántas veces se repite
animation-directionnormal, reverse, alternateSi rebota de vuelta o siempre igual
animation-fill-modenone, forwards, backwards, bothQué estilo queda ANTES/DESPUÉS de correr
animation-play-staterunning, pausedPausar/reanudar (útil con JS)

Nota sobre fill-mode: si tu animación empieza en opacity:0 y no pones fill-mode: forwards (o both), el elemento vuelve a su estado ORIGINAL del CSS (probablemente opacity:1) apenas termina la animación — un bug muy común.

4. Timing functions (curvas de aceleración)

Definen si el movimiento es constante, o si acelera/frena en algún punto. Prueba cada botón.

// selecciona una curva ↓
linearvelocidad constante, sin aceleración
ease(default) acelera al inicio, frena al final — la más natural
ease-inempieza lento, termina rápido
ease-outempieza rápido, termina lento
ease-in-outlento-rápido-lento
cubic-bezier(x1,y1,x2,y2)curva 100% personalizada — usa cubic-bezier.com para diseñarla visualmente

5. Catálogo de animaciones comunes

Las que más se repiten en proyectos reales. Copia el @keyframes y el nombre que quieras.

fade-in / fade-out

@keyframes fade-in {
  from { opacity: 0; }
  to   { opacity: 1; }
}
.el { animation: fade-in 1.2s ease both; }

slide-in (izquierda / derecha)

@keyframes slide-in-right {
  from { transform: translateX(-90px); opacity: 0; }
  to   { transform: translateX(0); opacity: 1; }
}
/* para que venga de la derecha, usa translateX(90px) */

scale-in (con rebote)

@keyframes scale-in {
  from { transform: scale(0); opacity: 0; }
  to   { transform: scale(1); opacity: 1; }
}
.el {
  animation: scale-in 0.6s cubic-bezier(.34,1.56,.64,1) both;
  /* esta curva es la que da el "rebote" al final */
}

bounce (loop infinito)

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-22px); }
}
.el { animation: bounce 1s ease-in-out infinite; }

pulse (loop infinito)

@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50%      { transform: scale(1.15); opacity: 0.7; }
}
.el { animation: pulse 1.4s ease-in-out infinite; }

shake (error / validación)

@keyframes shake {
  0%, 100% { transform: translateX(0); }
  20%      { transform: translateX(-8px); }
  40%      { transform: translateX(8px); }
  60%      { transform: translateX(-6px); }
  80%      { transform: translateX(6px); }
}
/* típico: input.classList.add('shake') al fallar validación */

spin (loading spinner)

@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.el { animation: spin 1.6s linear infinite; }
/* linear es clave aquí: un spinner no debe acelerar/frenar */

flip 3D

@keyframes flip {
  from { transform: rotateY(0deg); }
  to   { transform: rotateY(360deg); }
}
.contenedor { perspective: 400px; } /* da profundidad 3D */
.el { animation: flip 1.4s ease-in-out infinite; }

tu caso: balota que entra girando y desaparece

@keyframes ball-cycle {
  0%   { opacity:0; transform:scale(0) rotate(180deg); }
  15%  { opacity:1; transform:scale(1) rotate(0deg); }
  85%  { opacity:1; transform:scale(1) rotate(0deg); }
  100% { opacity:0; transform:scale(0.7) rotate(0deg); }
}
.el { animation: ball-cycle 3.5s ease-in-out; }
// para reiniciar con JS: remove clase → forzar reflow → add clase

6. requestAnimationFrame (JS)

Solo cuando el movimiento depende de algo en tiempo real: posición de otro elemento, input del usuario, física, colisiones. Si es un guion fijo, usa @keyframes.

Patrón base

function animar() {
  // 1. lees el estado real (posición, tiempo, lo que sea)
  const rect = elemento.getBoundingClientRect();

  // 2. calculas el siguiente estado
  x += velocidad;

  // 3. aplicas el cambio
  elemento.style.transform = `translateX(${x}px)`;

  // 4. pides el siguiente frame (~60 veces por segundo)
  requestAnimationFrame(animar);
}
requestAnimationFrame(animar);

Para cancelarlo: guarda el id que retorna requestAnimationFrame() y usa cancelAnimationFrame(id).

7. GSAP (GreenSock Animation Platform)

Librería JS para animaciones complejas: timelines encadenadas, easing avanzado, scroll-triggers, y control total (pausar/reversar/reescalar) que CSS puro no te da fácilmente.

Instalación — opción 1: CDN (rápido, sin build tools)

<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<!-- ya tienes la variable global "gsap" disponible -->

Instalación — opción 2: npm (proyectos con bundler)

# en tu terminal
npm install gsap
// en tu archivo JS
import { gsap } from "gsap";

gsap.to() — anima HACIA estos valores

gsap.to("#g-to", {
  x: 150,
  rotation: 360,
  duration: 1.2,
  ease: "back.out(1.7)" // easing propio de GSAP
});

gsap.from() — anima DESDE estos valores hasta el estado actual

gsap.from("#card", {
  opacity: 0,
  y: 40,
  duration: 0.8
});
// útil para animaciones de entrada: no defines el estado final,
// GSAP asume que el final es como ya está en el CSS/HTML

gsap.timeline() — encadenar pasos en orden

const tl = gsap.timeline();

tl.to("#g-tl", { scale: 1.4, duration: 0.4 })
  .to("#g-tl", { x: 120, duration: 0.6 })
  .to("#g-tl", { rotation: 360, duration: 0.5 })
  .to("#g-tl", { x: 0, scale: 1, duration: 0.5 });
// cada .to() empieza cuando termina el anterior, en orden

stagger — animar varios elementos con retraso escalonado

gsap.from(".bola", {
  y: -30,
  opacity: 0,
  duration: 0.5,
  stagger: 0.15 // 0.15s de diferencia entre cada una
});
// ideal para tus 77 bolas apareciendo en cascada

ScrollTrigger (plugin aparte)

<!-- necesitas cargar el plugin además del core -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js"></script>

gsap.registerPlugin(ScrollTrigger);

gsap.to(".seccion", {
  opacity: 1,
  y: 0,
  scrollTrigger: {
    trigger: ".seccion",
    start: "top 80%" // se activa cuando el top de .seccion llega al 80% del viewport
  }
});

¿CSS o GSAP? Regla rápida

SituaciónUsa
Hover, fade, spinner, loop simpleCSS (transition / @keyframes)
Secuencia de varios elementos en orden específicoGSAP timeline()
Animar según scrollGSAP + ScrollTrigger
Necesitas pausar/revertir/reescalar en tiempo real desde JSGSAP
Miles de elementos, rendimiento críticoCSS (el navegador lo optimiza más)
