Despliegue Cronológico de Entorno de Desarrollo e IA

Guía paso a paso diseñada para estaciones de trabajo (como HP ZBook G6) en entorno nativo o virtualizado con VMware. Configura VS Code, Google Antigravity, OpenCode, uv, fnm y Docker de forma 100% nativa, evitando conflictos de permisos de paquetes Snap.

PASO 00

Configuración Previa en VMware y Solución de Arranque

VMware Workstation

Antes de encender la máquina virtual por primera vez, ajusta los recursos asignados desde Edit virtual machine settings para evitar cuellos de botella y bloqueos en la pantalla inicial.

Memoria RAM

Asigna 16384 MB (16 GB) en sistemas con 32 GB físicos para correr IDEs Electron y contenedores sin usar swap.

Procesador (CPU)

Asigna 6 u 8 núcleos y marca "Virtualize Intel VT-x/EPT or AMD-V/RVI" para habilitar Docker anidado.

Almacenamiento NVMe

Crea un disco de 100 GB sobre controlador NVMe guardado en tu SSD interno para máxima velocidad de I/O.

Pantalla y 3D

En Display, desmarca "Accelerate 3D graphics" durante la instalación si el arranque se congela.

⚠ Nota sobre el mensaje "piix4_smbus: SMBus Host Controller not enabled!"
Este aviso en rojo es normal en VMware (el bus físico de sensores no se emula). Sin embargo, si la pantalla se queda congelada más de 1 minuto ahí, apaga la VM, desactiva "Accelerate 3D graphics" en Display y vuelve a arrancar; el conflicto gráfico de la ISO con la GPU virtual es lo que detiene la carga del escritorio.
PASO 01

Actualización del Sistema e Integración VMware Tools

Linux Mint Ubuntu

Con el sistema operativo recién instalado, abre la terminal (Ctrl + Alt + T) y actualiza los repositorios base junto con las herramientas esenciales de compilación e integración con el anfitrión.

Actualizar paquetes e instalar utilidades base 
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git build-essential ca-certificates gnupg software-properties-common
¿Qué hace este comando?
  • apt update && apt upgrade -y: Sincroniza el índice de paquetes y actualiza todo el sistema sin pedir confirmación manual.
  • curl / wget / git: Herramientas indispensables para descargar instaladores, claves GPG y clonar repositorios.
  • build-essential / gnupg: Instala compiladores C/C++ (GCC, Make) y gestión de firmas criptográficas para repositorios externos.
Instalar Open VM Tools (Solo si usas VMware) 
sudo apt install -y open-vm-tools open-vm-tools-desktop
sudo reboot
¿Qué hace este comando?
  • open-vm-tools-desktop: Habilita el portapapeles bidireccional (copiar/pegar entre el host y Linux), arrastrar archivos y el autoajuste dinámico de resolución al maximizar la ventana de VMware.
  • sudo reboot: Reinicia la máquina virtual para cargar los controladores gráficos y de integración en el kernel.
✓ Verificación
Al volver a iniciar sesión, maximiza la ventana de VMware: el escritorio debe adaptarse automáticamente al tamaño completo de tu monitor.
PASO 02

Ajuste de Sesión Gráfica y Control Térmico

Mint (X11/Térmica) Ubuntu (Xorg)

Aplica el ajuste específico según tu distribución antes de instalar aplicaciones gráficas basadas en Electron.

[UBUNTU] Cambiar servidor gráfico de Wayland a Xorg 
# 1. Cierra tu sesión actual (Log Out) desde el menú superior derecho.
# 2. Haz clic en tu usuario, pulsa el engranaje (⚙️) abajo a la derecha y elige "Ubuntu on Xorg".
# 3. Inicia sesión y comprueba en terminal con:
echo $XDG_SESSION_TYPE
¿Por qué es necesario en Ubuntu?
  • Wayland dentro de VMware suele provocar parpadeos, menús desfasados o pantallas negras en VS Code y Antigravity.
  • Al elegir Ubuntu on Xorg, el comando echo $XDG_SESSION_TYPE devolverá x11, garantizando estabilidad total.
[LINUX MINT] Instalar daemon de control térmico (Instalación física) 
sudo apt install -y thermald
sudo systemctl enable --now thermald
¿Qué hace este comando?
  • Linux Mint ya usa X11 (Cinnamon) por defecto, por lo que no requiere cambiar de sesión gráfica.
  • Si instalas Mint directamente en hardware físico (como un Core i7 serie H), thermald regula dinámicamente las frecuencias y temperaturas del procesador bajo cargas de compilación.
PASO 03

Instalar Visual Studio Code (Paquete Nativo .deb)

Linux Mint Ubuntu

Instalaremos VS Code desde el repositorio oficial de Microsoft para recibir actualizaciones automáticas vía apt y evitar el aislamiento restrictivo de Snap.

Añadir repositorio oficial de Microsoft e instalar VS Code 
curl -fsSL https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor --yes -o /usr/share/keyrings/microsoft.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
sudo apt update && sudo apt install -y code
Explicación línea por línea:
  • Línea 1: Descarga la clave pública de firma de Microsoft y la convierte al formato binario GPG en /usr/share/keyrings/.
  • Línea 2: Registra la URL del repositorio estable de VS Code vinculándolo únicamente a esa clave de seguridad.
  • Línea 3: Refresca la lista de paquetes e instala el binario nativo code.
✓ Verificación
Ejecuta code --version en la terminal; debe mostrar la versión instalada y la arquitectura x64.
PASO 04

Instalar Google Antigravity IDE y CLI (agy)

Linux Mint Ubuntu

Configura el repositorio oficial APT de Google para instalar tanto la interfaz gráfica de Antigravity IDE como su herramienta de línea de comandos agy.

Configurar repositorio oficial de Google Antigravity 
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://us-central1-apt.pkg.dev/doc/repo-signing-key.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/antigravity-repo-key.gpg
echo "deb [signed-by=/etc/apt/keyrings/antigravity-repo-key.gpg] https://us-central1-apt.pkg.dev/projects/antigravity-auto-updater-dev/ antigravity-debian main" | sudo tee /etc/apt/sources.list.d/antigravity.list > /dev/null
sudo apt update && sudo apt install -y antigravity
Explicación línea por línea:
  • Línea 1: Asegura que exista el directorio estándar /etc/apt/keyrings para llaves de repositorios de terceros.
  • Línea 2: Descarga y almacena la clave GPG oficial del Artifact Registry de Google para Antigravity.
  • Línea 3: Crea el archivo antigravity.list apuntando al canal oficial Debian/Ubuntu.
  • Línea 4: Instala el paquete completo antigravity (incluye el IDE y el ejecutable agy en el PATH).
✓ Verificación
Ejecuta agy --version para validar el CLI, o abre cualquier carpeta de proyecto con agy .
PASO 05

Instalar Agente IA OpenCode

Linux Mint Ubuntu

OpenCode se instala mediante su script oficial binario, permitiendo que el agente interactúe directamente con tu terminal, sistema de archivos y Git sin depender de contenedores aislados.

Instalación directa del binario de OpenCode 
curl -fsSL https://opencode.ai/install | bash
source ~/.bashrc
¿Qué hace este comando?
  • curl -fsSL https://opencode.ai/install | bash: Descarga el binario precompilado compatible con tu arquitectura Linux y lo ubica en ~/.opencode/bin.
  • source ~/.bashrc: Recarga la configuración de tu terminal actual para reconocer inmediatamente el comando opencode sin tener que cerrar la ventana.
✓ Verificación
Ejecuta opencode --version. Para iniciarlo en un proyecto, entra a la carpeta y escribe opencode.
PASO 06

Gestores Modernos de Python (uv) y Node.js (fnm)

Linux Mint Ubuntu

Nunca instales paquetes con sudo pip ni uses versiones antiguas de Node de los repositorios base. Usa uv y fnm para que los agentes IA creen entornos aislados a máxima velocidad.

Instalar uv (Gestor ultrarrápido de Python) 
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc
¿Qué hace este comando?
  • Instala uv (escrito en Rust), capaz de descargar versiones de Python, crear entornos virtuales (uv venv) e instalar dependencias 10x–100x más rápido que pip tradicional.
Instalar fnm (Fast Node Manager) y Node.js LTS 
curl -fsSL https://fnm.vercel.app/install | bash
source ~/.bashrc
fnm install --lts
fnm default lts-latest
¿Qué hace este comando?
  • Líneas 1-2: Instala fnm (gestor ligero de Node.js en Rust) y actualiza el PATH en ~/.bashrc.
  • Líneas 3-4: Descarga la última versión estable de soporte extendido (LTS) de Node.js junto con npm y npx, dejándola configurada por defecto.
✓ Verificación
Ejecuta uv --version, node -v y npm -v para confirmar que ambos runtimes están activos.
PASO 07

Instalar Docker Engine Nativo (Sin Docker Desktop ni Snap)

Linux Mint Ubuntu

Instala el motor oficial de Docker y Docker Compose directamente sobre el kernel Linux para levantar bases de datos (PostgreSQL, MySQL, Redis) o servicios locales con mínimo consumo de RAM.

Instalación oficial de Docker Engine y permisos de usuario 
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
Explicación línea por línea:
  • Línea 1: Ejecuta el script oficial de Docker que detecta automáticamente si estás en Ubuntu o Linux Mint, configura el repositorio e instala docker-ce y el plugin docker compose.
  • Línea 2: Añade tu usuario actual al grupo docker para poder ejecutar contenedores sin escribir sudo cada vez (vital para que los agentes IA ejecuten contenedores).
  • Línea 3: Aplica el cambio de grupo en la sesión de terminal actual sin necesidad de reiniciar.
✓ Verificación
Ejecuta docker run --rm hello-world; debe descargar la imagen de prueba e imprimir "Hello from Docker!" sin pedir contraseña.
PASO 08

Solución Preventiva de Gráficos Electron en VMware

Opcional / VMware

Si al abrir VS Code o Antigravity IDE dentro de VMware notas pantallas negras, parpadeos o texto difuso debido a la emulación de GPU virtual, desactiva la aceleración por hardware en ambos editores.

Configurar argv.json para desactivar aceleración GPU en ambos IDEs 
mkdir -p ~/.config/Code/User ~/.config/Antigravity/User

cat << 'EOF' > ~/.config/Code/User/argv.json
{
    "disable-hardware-acceleration": true
}
EOF

cp ~/.config/Code/User/argv.json ~/.config/Antigravity/User/argv.json
¿Qué hace este comando?
  • Crea los directorios de configuración inicial si aún no has abierto los IDEs por primera vez.
  • Escribe el parámetro "disable-hardware-acceleration": true en el archivo argv.json tanto de VS Code como de Google Antigravity, forzando un renderizado por CPU totalmente nítido y libre de fallos gráficos en máquinas virtuales.
✓ Entorno Completado
Ya tienes todo tu stack listo. Puedes abrir tu proyecto con code . o agy . y lanzar el agente en terminal con opencode.
