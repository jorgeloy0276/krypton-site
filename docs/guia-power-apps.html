Referencia Maestra de Power Apps & Power Fx

Compendio técnico con arquitectura de arranque desde cero, catálogo exhaustivo de fórmulas para lógica, datos, controles de interfaz e integración nativa con Power Automate, Microsoft Forms, Outlook y Teams.

Power Fx (ES / EN) Canvas Apps Microsoft 365 Connectors Delegación & Buenas Prácticas
Nota de Sintaxis Regional: En entornos configurados en español, el separador de argumentos es ; y el encadenamiento de comandos es ;;. En inglés, se usa , y ; respectivamente. Todos los ejemplos aquí usan la sintaxis estándar internacional (, y ;) para evitar conflictos de copia directa; Power Apps los traduce automáticamente si los pegas en la barra de fórmulas o puedes ajustarlos según tu región.

01 Iniciar un Proyecto desde Cero (Checklist de Arquitectura)

Paso 1: Capa de Datos (Antes de abrir Power Apps Studio)

Define el origen de datos según volumen, seguridad y licenciamiento:

  • SharePoint Lists: Ideal para licencias estándar M365. Usa columnas simples (Texto, Número, Fecha, Persona) y evita columnas "Lookup" complejas para prevenir problemas de delegación.
  • Microsoft Dataverse: Recomendado para relaciones complejas, seguridad a nivel de fila y entornos empresariales (requiere licencia Premium).
  • SQL Server / PostgreSQL: Para alto volumen transaccional y vistas/procedimientos almacenados.

Paso 2: Configuración Inicial en Power Apps Studio

  • Crear aplicación Lienzo en blanco (Blank Canvas App) → Elegir formato Tableta (16:9) para escritorio/web o Teléfono para uso móvil.
  • Ir a Configuración → Pantalla: Desactivar "Ajustar escala para llenar" si deseas diseño responsivo real con contenedores (Horizontal/Vertical Containers).
  • Ir a Configuración → Próximas características: Activar Fórmulas con nombre (Named Formulas) y Funciones definidas por el usuario (UDFs).

Paso 3: Convención de Nombres (Estándar Oficial Microsoft)

Paso 4: Configuración de App.Formulas y App.OnStart

Usa App.Formulas (inmutables y reactivas) para constantes y perfil del usuario en lugar de sobrecargar OnStart:

// En la propiedad App.Formulas (No requiere Set ni se recalcula manualmente)
fxUsuarioActual = User();
fxEsAdmin = !IsBlank(LookUp(Administradores, Correo = User().Email));
fxColorPrimario = ColorValue("#742774");
fxColorFondo = ColorValue("#F8FAFC");
fxVersionApp = "v2.4.0";

02 Variables, Contexto y Estado

Set() — Variable Global Toda la App

Crea o actualiza una variable accesible desde cualquier pantalla de la aplicación.

Set(gblRegistroSeleccionado, ThisItem);
Set(gblContador, gblContador + 1);
Set(gblRegistroSeleccionado, Blank()); // Limpiar variable
UpdateContext() — Variable Local Pantalla Actual

Crea variables que solo existen en la pantalla actual (ideal para modales, pestañas o estados de carga).

UpdateContext({
    locMostrarModal: true,
    locModoEdicion: false,
    locMensajeError: ""
});
With() — Variable Temporal de Cálculo Bloque Local

Evalúa valores intermedios dentro de una sola fórmula para evitar repetir consultas lentas o cálculos complejos.

With(
    {
        wSubtotal: Value(txtCantidad.Text) * Value(txtPrecio.Text),
        wTasaITBMS: 0.07
    },
    wSubtotal + (wSubtotal * wTasaITBMS)
)
Reset() & ResetForm() Controles

Restablece un control o formulario completo a su propiedad Default.

Reset(txtBuscar);
Reset(drpEstado);
ResetForm(frmSolicitud);
NewForm(frmSolicitud); // Prepara formulario para crear nuevo registro

03 Navegación, Pantallas y Sesión

Navigate() & Back() OnSelect

Cambia de pantalla con transición opcional y envía parámetros de contexto directamente a la pantalla destino.

Navigate(
    scrDetalle,
    ScreenTransition.Fade,
    { locIdRecibido: ThisItem.ID, locSoloLectura: true }
);

// Volver a la pantalla anterior
Back(ScreenTransition.CoverRight);
Launch() & Param() & Exit() URLs / Deep Linking

Abre URLs externas, lee parámetros enviados por URL (Deep Linking) o cierra la aplicación.

// Abrir enlace en nueva pestaña
Launch("https://portal.empresa.com/ticket/" & ThisItem.ID);

// Leer parámetro de URL al abrir app (?ticketId=105)
Set(gblTicketURL, Param("ticketId"));

// Cerrar sesión / salir de la app
Exit(true);

04 Operaciones de Datos y CRUD (Delegables)

Patch() — Crear Registro Insertar

Inserta un nuevo registro en el origen de datos usando Defaults() y captura el registro creado.

Set(
    gblNuevoRegistro,
    Patch(
        TicketsSoporte,
        Defaults(TicketsSoporte),
        {
            Title: txtAsunto.Text,
            Descripcion: txtDetalle.Text,
            Prioridad: drpPrioridad.Selected.Value,
            FechaCreacion: Now(),
            SolicitanteCorreo: User().Email
        }
    )
);
Patch() — Actualizar Registro Modificar

Actualiza únicamente las columnas especificadas en un registro existente localizado por LookUp().

Patch(
    TicketsSoporte,
    LookUp(TicketsSoporte, ID = gblRegistroSeleccionado.ID),
    {
        Estado: "Resuelto",
        ComentariosCierre: txtSolucion.Text,
        FechaCierre: Now()
    }
);
Filter(), Search() & SortByColumns() Galerías / Tablas

Filtra y ordena registros de forma delegable en el servidor.

SortByColumns(
    Filter(
        TicketsSoporte,
        (drpEstado.Selected.Value = "Todos" || Estado = drpEstado.Selected.Value) &&
        (IsBlank(txtBuscar.Text) || StartsWith(Title, txtBuscar.Text))
    ),
    "Created",
    SortOrder.Descending
)
LookUp() — Buscar Registro Único Búsqueda Exacta

Devuelve el primer registro que cumple la condición, o extrae directamente un campo específico.

// Obtener el registro completo
Set(gblCliente, LookUp(Clientes, RUC = txtRUC.Text));

// Obtener solo un campo (ej. Nombre del departamento)
LookUp(Departamentos, Codigo = ThisItem.DeptoID, Nombre)
Remove() & RemoveIf() Eliminar

Elimina un registro específico o todos los que cumplan una condición.

// Eliminar registro puntual
Remove(TicketsSoporte, ThisItem);

// Eliminar registros temporales de una colección
RemoveIf(colCarrito, Cantidad <= 0);
Refresh() & SubmitForm() Formularios

Guarda un control EditForm y gestiona acciones en OnSuccess y OnFailure.

// En botón Guardar
SubmitForm(frmSolicitud);

// En propiedad OnSuccess de frmSolicitud
Notify("Registro guardado con ID: " & frmSolicitud.LastSubmit.ID, NotificationType.Success);
Back();

05 Colecciones y Manipulación de Tablas en Memoria

ClearCollect() & Collect() Memoria Local

Crea colecciones locales en RAM para listas desplegables, carritos de compra o caché rápido.

ClearCollect(
    colEstados,
    { Id: 1, Nombre: "Pendiente", Color: "#F59E0B" },
    { Id: 2, Nombre: "En Proceso", Color: "#38BDF8" },
    { Id: 3, Nombre: "Completado", Color: "#10B981" }
);

// Agregar ítem sin borrar los existentes
Collect(colCarrito, { ProductoId: ThisItem.ID, Cantidad: 1 });
ForAll() — Bucle / Iteración masiva Procesamiento Lote

Ejecuta una acción o transformación por cada fila de una tabla o galería (ej. guardar líneas de una factura).

ForAll(
    colCarrito As ItemCarrito,
    Patch(
        DetalleFactura,
        Defaults(DetalleFactura),
        {
            FacturaID: gblNuevaFactura.ID,
            Producto: ItemCarrito.Nombre,
            Cantidad: ItemCarrito.Cantidad,
            Subtotal: ItemCarrito.Cantidad * ItemCarrito.Precio
        }
    )
);
AddColumns(), DropColumns(), RenameColumns() Moldeo de Tablas

Transforma la estructura de una tabla virtual sin modificar el origen de datos.

AddColumns(
    Ventas,
    "TotalConImpuesto", Precio * Cantidad * 1.07,
    "NombreCompleto", Nombre & " " & Apellido
)
GroupBy(), Ungroup(), Distinct() Agrupación

Obtiene valores únicos para filtros o agrupa registros para reportes y gráficos.

// Valores únicos para un Dropdown
Distinct(Empleados, Departamento)

// Agrupar ventas por categoría
GroupBy(Ventas, "Categoria", "RegistrosCategoria")
First(), Last(), FirstN(), Index() Posición

Accede a registros por su posición dentro de una tabla o colección.

First(colHistorial).Fecha
Last(colHistorial).Comentario
FirstN(Sort(Productos, Ventas, SortOrder.Descending), 5) // Top 5
Index(colPasos, 3).Titulo // Tercer elemento exacto
Sequence() — Generador de Series Dinámico

Genera una tabla numérica al vuelo (útil para paginación, calendarios, estrellas de calificación o repeticiones).

// Generar 12 meses [1..12]
Sequence(12, 1, 1)

// Generar los próximos 7 días desde hoy
ForAll(Sequence(7, 0, 1), DateAdd(Today(), Value, TimeUnit.Days))

06 Lógica, Condicionales y Manejo de Errores

If() & Switch() Condicionales

Evalúa múltiples condiciones o compara una expresión contra valores exactos.

Switch(
    ThisItem.Prioridad,
    "Alta", Color.Red,
    "Media", Color.Orange,
    "Baja", Color.Green,
    Color.Gray // Valor por defecto
)
Coalesce() & IsBlank() & IsEmpty() Validación Nulos

Coalesce devuelve el primer argumento que no esté en blanco. IsBlank evalúa valores/campos; IsEmpty evalúa tablas.

// Mostrar texto alternativo si el campo es nulo
Coalesce(ThisItem.TelefonoSecundario, ThisItem.TelefonoPrincipal, "Sin teléfono")

// Validar formulario antes de enviar
If(
    IsBlank(txtNombre.Text) || IsEmpty(colItems),
    Notify("Complete los campos obligatorios", NotificationType.Warning),
    SubmitForm(frmDatos)
)
IfError() & IsError() & Errors() Try / Catch

Captura errores en tiempo de ejecución (como fallos de red o permisos en Patch) sin mostrar banners rojos al usuario.

IfError(
    Patch(Inventario, ThisItem, { Stock: ThisItem.Stock - 1 }),
    Notify("Error al actualizar stock: " & FirstError.Message, NotificationType.Error),
    Notify("Stock actualizado correctamente", NotificationType.Success)
)
Concurrent() — Ejecución Paralela Rendimiento

Ejecuta múltiples llamadas a conectores simultáneamente en OnStart o OnVisible reduciendo el tiempo de carga hasta un 70%.

Concurrent(
    ClearCollect(colClientes, Clientes),
    ClearCollect(colProductos, Productos),
    ClearCollect(colCategorias, Categorias)
);

07 Texto, Formato y Expresiones Regulares

Concat() vs Concatenate() Unión de Cadenas

Concatenate (o &) une cadenas sueltas. Concat une una columna de toda una tabla en un solo texto.

// Unir todos los correos de una colección separados por punto y coma
Concat(colDestinatarios, Correo, "; ")

// Interpolación moderna de cadenas ($"...")
$"Hola {User().FullName}, tienes {CountRows(colTareas)} tareas pendientes."
IsMatch() & Match() — Validación RegEx Validación

Valida correos electrónicos, teléfonos, formatos de cédula o extrae patrones mediante expresiones regulares.

// Validar formato de correo electrónico
IsMatch(txtCorreo.Text, Match.Email)

// Validar patrón personalizado (ej. Código TIC-2026-001)
IsMatch(txtCodigo.Text, "^TIC-\d{4}-\d{3}$")
Left(), Mid(), Right(), Split(), Substitute() Extracción

Manipula subcadenas, divide textos por delimitadores y limpia caracteres.

// Obtener iniciales de nombre y apellido
Upper(Left(First(Split(User().FullName, " ")).Value, 1) & 
      Left(Last(Split(User().FullName, " ")).Value, 1))

// Reemplazar texto
Substitute(Trim(txtInput.Text), "-", "")
JSON() & ParseJSON() Intercambio Datos

Serializa colecciones/imágenes a texto JSON para enviar a Power Automate, o lee respuestas JSON complejas.

// Convertir colección (incluyendo imágenes) a JSON
JSON(colEvidencias, JSONFormat.IncludeBinaryData)

// Leer respuesta JSON desde un flujo
Text(ParseJSON(gblRespuestaFlujo).estado)

08 Fechas, Horas y Cálculos de Calendario

Text() — Formateo de Fechas y Moneda Visualización

Formatea fechas, horas y números monetarios para etiquetas visuales.

Text(Now(), "dd/mm/yyyy hh:mm AM/PM")
Text(Today(), "dddd, dd 'de' mmmm 'de' yyyy", "es-PA")
Text(1250.5, "$#,##0.00")
DateAdd() & DateDiff() Aritmética Temporal

Suma o resta días, horas o meses, y calcula diferencias exactas entre dos fechas.

// Sumar 15 días a hoy
DateAdd(Today(), 15, TimeUnit.Days)

// Días transcurridos desde la creación del ticket
DateDiff(ThisItem.FechaCreacion, Now(), TimeUnit.Days)

// Primer y último día del mes actual
Date(Year(Today()), Month(Today()), 1)
DateAdd(DateAdd(Date(Year(Today()), Month(Today()), 1), 1, TimeUnit.Months), -1, TimeUnit.Days)

09 Matemáticas, Agregaciones y Estadística

Sum(), Average(), Min(), Max(), CountRows() KPIs / Tarjetas

Calcula totales y métricas sobre colecciones o galerías filtradas.

// Total de la galería actual
Sum(galItems.AllItems, Subtotal)

// Contar registros filtrados
CountRows(Filter(Tickets, Estado = "Abierto"))

// Promedio redondeado a 2 decimales
Round(Average(Encuestas, Calificacion), 2)
Round(), RoundUp(), RoundDown(), Mod(), RandBetween() Numérico

Funciones matemáticas de precisión, residuos y aleatoriedad.

RoundUp(TotalHoras, 0) // Redondea siempre hacia arriba
Mod(ThisItem.Indice, 2) = 0 // Detectar fila par para efecto cebra
RandBetween(100000, 999999) // Código PIN aleatorio de 6 dígitos

10 Fórmulas para Objetos, Controles y Diseño UI

Posicionamiento Responsivo (X, Y, Width, Height) Layout Dinámico

Alinea controles dinámicamente respecto a la pantalla o a controles hermanos sin usar números fijos.

// Centrar un modal en pantalla
X: (App.Width - Self.Width) / 2
Y: (App.Height - Self.Height) / 2

// Ubicar control 16px debajo del control anterior
Y: lblTitulo.Y + lblTitulo.Height + 16
Width: Parent.Width - 32
Galerías: TemplateFill, IsSelected, AllItems Gallery

Resalta el ítem seleccionado, aplica filas alternas (efecto cebra) y lee valores editados dentro de una galería.

// En propiedad TemplateFill de la galería
If(
    ThisItem.IsSelected,
    ColorFade(fxColorPrimario, 0.85),
    If(Mod(ThisItem.ID, 2) = 0, ColorValue("#F8FAFC"), Color.White)
)

// Leer valor de un TextInput dentro de la galería
Sum(galDetalle.AllItems, Value(txtCantidadFila.Text))
Estados de Botón (DisplayMode) & Visibilidad UX / Validación

Deshabilita botones automáticamente si el formulario es inválido o si está procesando una petición.

// En propiedad DisplayMode de btnGuardar
If(
    frmSolicitud.Valid && !locCargando,
    DisplayMode.Edit,
    DisplayMode.Disabled
)

// En propiedad Visible de botones administrativos
fxEsAdmin
Colores Dinámicos: ColorValue(), RGBA(), ColorFade() Estilos

Define paletas corporativas en hexadecimal y calcula estados HoverFill y PressedFill automáticamente.

Fill: ColorValue("#742774")
HoverFill: ColorFade(Self.Fill, -0.15) // 15% más oscuro
PressedFill: ColorFade(Self.Fill, -0.30)
DisabledFill: RGBA(148, 163, 184, 0.4)

11 Integración Bidireccional con Power Automate

1. Configuración del Flujo en Power Automate (Trigger V2)

  • Crear un Flujo de nube instantáneo con el desencadenador Power Apps (V2).
  • Definir entradas tipadas (Texto, Número, Booleano, Archivo/Imagen o Correo).
  • Ejecutar acciones (ej. generar PDF, insertar en SQL, llamar API REST, aprobar).
  • Finalizar con la acción Responder a una Power App o flujo devolviendo variables de salida (ej. urlArchivo, codigoEstado).

2. Invocación desde Power Apps y Captura de Respuesta

UpdateContext({ locCargando: true });

Set(
    gblResultadoFlujo,
    MiFlujoGenerarReporte.Run(
        ThisItem.ID,
        User().Email,
        JSON(colLineasReporte)
    )
);

UpdateContext({ locCargando: false });

// Usar el valor devuelto por Power Automate
If(
    !IsBlank(gblResultadoFlujo.urlpdf),
    Launch(gblResultadoFlujo.urlpdf),
    Notify("No se pudo generar el documento", NotificationType.Error)
);

12 Integración con Microsoft Forms

Arquitectura de Conexión: Power Apps no tiene un conector directo nativo para leer respuestas de MS Forms en tiempo real. La arquitectura estándar empresarial conecta MS Forms → Power Automate → SharePoint / Dataverse → Power Apps (o embebe Forms dentro de Power Apps).
Flujo Automatizado Forms → App Backend Sync

Cuando un usuario externo llena un MS Form, Power Automate captura los datos y los deposita en la base de datos de tu Power App.

// Arquitectura del Flujo:
1. Trigger: When a new response is submitted (MS Forms)
2. Action: Get response details (Response Id)
3. Action: Create item (SharePoint / Dataverse)
4. En Power Apps: Refresh(OrigenDatos) o galería auto-actualizada
Embeber MS Forms en Power Apps Control HTML / Launch

Puedes abrir el formulario pre-rellenado o incrustarlo mediante un control HtmlText (en entorno web) o lanzarlo con parámetros.

// Abrir formulario externo desde botón
Launch("https://forms.office.com/r/TuCodigoDeFormulario");

// Incrustar mediante iframe en control HtmlText
"<iframe width='100%' height='600px' src='https://forms.office.com/r/TuCodigo?embed=true' frameborder='0'></iframe>"

13 Conector Office 365 Outlook

Agregar origen de datos: Office365Outlook. Permite enviar correos HTML, adjuntar archivos, consultar calendario y crear reuniones.

Office365Outlook.SendEmailV2() Correo HTML

Envía correos con formato HTML enriquecido, copias (CC/BCC) e importancia alta.

Office365Outlook.SendEmailV2(
    txtDestinatario.Text,
    "Notificación de Solicitud #" & gblNuevoRegistro.ID,
    "<h3>Solicitud Registrada</h3>" &
    "<p>Estimado/a, su solicitud ha sido recibida con estado <b>Pendiente</b>.</p>",
    {
        Cc: User().Email,
        Importance: "High"
    }
);
SendEmailV2() con Archivos Adjuntos Attachments

Adjunta archivos cargados desde un control Attachments de un formulario o imágenes tomadas con la cámara.

Office365Outlook.SendEmailV2(
    "soporte@empresa.com",
    "Evidencia Adjunta",
    "Se adjuntan los archivos correspondientes.",
    {
        Attachments: ForAll(
            DataCardValueAdjuntos.Attachments,
            {
                Name: Name,
                ContentBytes: Value
            }
        )
    }
);
V4CalendarPostItem() — Agendar Reunión Calendario

Crea un evento en el calendario del usuario o programa una reunión con asistentes.

Office365Outlook.V4CalendarPostItem(
    LookUp(Office365Outlook.CalendarGetTablesV2().value, name = "Calendar").id,
    "Revisión de Proyecto",
    Text(dtpInicio.SelectedDate, DateTimeFormat.UTC),
    Text(DateAdd(dtpInicio.SelectedDate, 1, TimeUnit.Hours), DateTimeFormat.UTC),
    "(UTC-05:00) Bogota, Lima, Quito, Rio Branco",
    {
        RequiredAttendees: "colega@empresa.com",
        Body: "Sesión de seguimiento generada desde Power Apps.",
        IsHtml: true
    }
);
Office365Users — Perfil y Jefatura Directorio Activo

Complemento esencial junto a Outlook para obtener el gerente (aprobador), foto y departamento del usuario.

// Obtener correo del jefe directo para flujo de aprobación
Office365Users.ManagerV2(User().Email).mail

// Obtener foto de perfil (en propiedad Image)
If(
    Office365Users.UserPhotoMetadata(User().Email).HasPhoto,

)

14 Conector Microsoft Teams

Agregar origen de datos: MicrosoftTeams. Permite publicar mensajes en canales, enviar chats directos y crear reuniones de Teams.

PostMessageToChannelV3() Canal de Equipo

Publica una notificación formateada en HTML dentro de un canal específico de un equipo de Teams.

MicrosoftTeams.PostMessageToChannelV3(
    "ID-DEL-EQUIPO-GUID",
    "19:id-del-canal@thread.tacv2",
    {
        content: "<b>Nuevo Ticket Crítico:</b> " & txtAsunto.Text & "<br>Asignado a: " & cmbTecnico.Selected.DisplayName,
        contentType: "html"
    },
    {
        subject: "Alerta de Soporte #" & gblNuevoRegistro.ID
    }
);
CreateChat() & PostMessageToConversation() Chat Directo 1:1

Inicia una conversación privada con un usuario y envía un mensaje directo desde la app.

With(
    {
        wChat: MicrosoftTeams.CreateChat(
            User().Email & ";" & cmbAprobador.Selected.Mail,
            { topic: "Aprobación Pendiente" }
        )
    },
    MicrosoftTeams.PostMessageToConversation(
        "Flow bot",
        "Chat with flow bot",
        {
            recipient: cmbAprobador.Selected.Mail,
            messageBody: "Hola, tienes una solicitud pendiente en Power Apps."
        }
    )
);
CreateTeamsMeeting() Videollamada

Genera una reunión de Teams instantánea o programada y devuelve el enlace joinUrl.

Set(
    gblReunionTeams,
    MicrosoftTeams.CreateTeamsMeeting(
        LookUp(Office365Outlook.CalendarGetTablesV2().value, name = "Calendar").id,
        "Soporte Remoto Ticket #" & ThisItem.ID,
        "Sesión técnica generada desde la aplicación.",
        "UTC",
        { dateTime: Text(Now(), DateTimeFormat.UTC) },
        { dateTime: Text(DateAdd(Now(), 30, TimeUnit.Minutes), DateTimeFormat.UTC) },
        true,
        "teamsForBusiness",
        { requiredAttendees: ThisItem.SolicitanteCorreo }
    )
);
// Unirse inmediatamente
Launch(gblReunionTeams.onlineMeeting.joinUrl);
Host Object (Cuando la App corre dentro de Teams) Contexto Teams

Detecta si la aplicación está incrustada como pestaña en Microsoft Teams para adaptar el tema visual (oscuro/claro) o leer el ID del canal.

// Detectar tema oscuro de Teams
If(
    Param("theme") = "dark",
    ColorValue("#1F1F1F"),
    ColorValue("#FFFFFF")
)

// Obtener ID del equipo donde está alojada la pestaña
Param("groupId")
