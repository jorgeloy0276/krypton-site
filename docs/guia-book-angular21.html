TypeScript Esencial
Antes de Angular necesitas entender TypeScript. Tipos, interfaces, clases, genéricos y utility types son el vocabulario diario del desarrollador Angular.
📐 Tipos Básicos e Interfaces TypeScript
TypeScript

Las interfaces son el contrato de tus datos. Son el principal modo de modelar la respuesta de una API o el estado de un componente.

// Tipos primitivos
let nombre:  string  = 'Angular';
let version: number  = 21;
let activo:  boolean = true;
let datos:   any     = {};      // evitar en lo posible
let valor:   unknown = 42;    // más seguro que any

// Interface — contrato de tipo (para DTOs y modelos)
export interface Usuario {
  id:         number;
  nombre:     string;
  email:      string;
  rol:        'admin' | 'usuario' | 'invitado'; // union
  createdAt?: Date;     // ? = opcional
}

// Type alias (más flexible que interface)
type Estado = 'idle' | 'loading' | 'success' | 'error';
type ID     = number | string;

// Genéricos — respuesta paginada de API
interface Paginated<T> {
  data:     T[];
  total:    number;
  page:     number;
  pageSize: number;
}
// uso: Paginated<Usuario>, Paginated<Producto>

// Utility Types — muy usados en Angular
type Partial<Usuario>  // todos opcionales (PATCH)
type Required<Usuario> // todos requeridos
type Readonly<Usuario> // todo readonly
type Pick<Usuario, 'id' | 'nombre'> // solo esas props
type Omit<Usuario, 'password'>    // sin password
🏛️ Clases, Decoradores y Enums TypeScript
TypeScript

Angular está construido sobre clases TypeScript con decoradores. Entender los modificadores de acceso es clave.

// Clase con constructor shorthand
export class UsuarioModel {
  nombreCompleto: string;

  constructor(
    public    nombre:   string,  // public: accesible desde fuera
    private   email:    string,  // private: solo en esta clase
    protected rol:      string,  // protected: esta clase + hijos
    readonly  id:       number,  // readonly: no se puede cambiar
  ) {
    this.nombreCompleto = `${nombre}`;
  }

  esAdmin(): boolean { return this.rol === 'admin'; }
}

// Enum de string (común en Angular)
export enum EstadoPedido {
  Pendiente  = 'PENDIENTE',
  Procesando = 'PROCESANDO',
  Entregado  = 'ENTREGADO',
}

// Mejor alternativa: const object (tree-shakeable)
export const ROLES = {
  ADMIN:    'admin',
  USUARIO:  'usuario',
} as const;
export type Rol = typeof ROLES[keyof typeof ROLES];
// Rol = 'admin' | 'usuario'

// Decoradores (Angular los define sobre clases/propiedades)
@Component({ ... })   // marca la clase como Componente
@Injectable({ ... }) // marca la clase como Servicio
@Input()              // marca una prop como Input

El Componente — Unidad Básica
Todo en Angular es un componente. Aprende su anatomía, el decorador @Component, el ciclo de vida y la proyección de contenido.
🧩 Anatomía de un Componente Standalone @Component
Angular

Un componente combina lógica (TypeScript), vista (HTML) y estilos (CSS/SCSS). El decorador @Component lo registra en Angular.

// app.component.ts
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';

@Component({
  selector:    'app-root',      // tag HTML: <app-root>
  standalone:  true,           // sin NgModule (v17+, default)
  imports:     [RouterOutlet],  // qué necesita este componente
  templateUrl: './app.component.html',
  styleUrl:    './app.component.scss',
  // template: `<p>inline</p>`,  ← alternativa inline
  // styles:   [`h1 { color: red }`], ← estilos inline
})
export class AppComponent {
  title = 'mi-app';
  contador = 0;

  incrementar() { this.contador++; }
}

<!-- app.component.html -->
<h1>{{ title }}</h1>
<p>Contador: {{ contador }}</p>
<button (click)="incrementar()">+1</button>
🔄 Ciclo de Vida (Lifecycle Hooks) Lifecycle
Angular

Angular llama estos métodos en orden durante la vida del componente. Los más usados son ngOnInit y ngOnDestroy.

import { OnInit, OnDestroy, OnChanges, SimpleChanges,
         AfterViewInit } from '@angular/core';

@Component({ ... })
export class Demo implements OnInit, OnDestroy, OnChanges {

  // 1. constructor → solo inyectar dependencias
  constructor() {}

  // 2. ngOnChanges → cuando cambia un @Input
  ngOnChanges(changes: SimpleChanges) {
    if (changes['nombre'])
      console.log('Nuevo valor:', changes['nombre'].currentValue);
  }

  // 3. ngOnInit → inicialización, llamadas HTTP ✅ más usado
  ngOnInit() { /* cargar datos, iniciar subscriptions */ }

  // 4. ngDoCheck → detección manual (raro)
  // 5. ngAfterContentInit → ng-content listo
  // 6. ngAfterContentChecked

  // 7. ngAfterViewInit → template e hijos listos ✅
  ngAfterViewInit() { /* acceder a @ViewChild aquí */ }

  // 8. ngAfterViewChecked

  // 9. ngOnDestroy → limpieza ✅ cancelar subs, intervals
  ngOnDestroy() { /* limpiar todo para evitar memory leaks */ }
}

// ORDEN: constructor → ngOnChanges → ngOnInit →
//        ngAfterViewInit → (cambios) → ngOnDestroy

import { ViewChild, ElementRef, AfterViewInit } from '@angular/core';

Templates — Data Binding y Sintaxis
Cómo Angular conecta el TypeScript con el HTML. Los 4 tipos de binding y la nueva sintaxis de bloques de control @if / @for / @switch.
🔗 Los 4 Tipos de Data Binding Core
HTML 
<!-- ① INTERPOLACIÓN: TypeScript → DOM (mostrar valor) -->
<h1>{{ titulo }}</h1>
<p>{{ 2 + 2 }}</p>
<p>{{ usuario?.nombre | uppercase }}</p>   <!-- optional chaining + pipe -->

<!-- ② PROPERTY BINDING: TypeScript → propiedad DOM [prop] -->
<img    [src]="imagenUrl" [alt]="descripcion" />
<button [disabled]="formulario.invalid">Enviar</button>
<div    [class.activo]="estaActivo"></div>     <!-- clase condicional -->
<div    [style.color]="color"></div>           <!-- estilo inline -->
<div    [ngClass]="{'activo': ok, 'error': !ok}"></div>
<div    [ngStyle]="{ color: 'red', fontSize: '14px' }"></div>
<td     [attr.colspan]="columnas"></td>         <!-- atributo HTML (no propiedad) -->

<!-- ③ EVENT BINDING: DOM → TypeScript (reaccionar a eventos) -->
<button (click)="guardar()">Guardar</button>
<input  (input)="onChange($event)">         <!-- $event = evento nativo -->
<input  (keyup.enter)="buscar()">            <!-- filtro de tecla -->
<form   (ngSubmit)="onSubmit()"></form>

<!-- ④ TWO-WAY BINDING: [(ngModel)] — requiere FormsModule -->
<input [(ngModel)]="email" />
<!-- equivale a: [value]="email" + (input)="email=$event.target.value" -->
🧱 Nueva Sintaxis: @if / @for / @switch v17+
v17+

Reemplazan a *ngIf, *ngFor y *ngSwitch. Son más legibles, no requieren importar nada y tienen mejor rendimiento.

<!-- @if — reemplaza *ngIf -->
@if (usuario()) {
  <p>Bienvenido, {{ usuario()?.nombre }}</p>
} @else if (cargando()) {
  <app-spinner></app-spinner>
} @else {
  <p>No hay sesión</p>
}

<!-- @for — reemplaza *ngFor (track obligatorio) -->
@for (item of items(); track item.id) {
  <li>{{ item.nombre }}</li>
} @empty {
  <p>No hay items</p>
}

<!-- Variables de @for -->
@for (item of lista; track item.id; let i = $index,
       first = $first, last = $last, even = $even) {
  <div [class.par]="even">{{ i }}: {{ item }}</div>
}

<!-- @switch -->
@switch (estado()) {
  @case ('activo')   { <span>✅</span> }
  @case ('error')    { <span>❌</span> }
  @default           { <span>❓</span> }
}

<!-- @let — variable local en template (v18+) -->
@let user = usuarioSignal();
<h1>{{ user.nombre + ' ' + user.apellido }}</h1>
🧰 ng-template y ng-container Template helpers
HTML 
<!-- ng-template: bloque sin renderizar (con referencia #) -->
<div *ngIf="cargando; else contenido">Cargando...</div>
<ng-template #contenido>
  <p>Datos cargados</p>
</ng-template>

<!-- ng-container: agrupa sin crear elemento DOM real -->
<!-- Útil cuando no quieres un div extra -->
<ng-container *ngIf="condicion">
  <p>Elemento A</p>
  <p>Elemento B</p>
</ng-container>

<!-- ng-container con dos directivas (no se puede en mismo elemento) -->

  <li *ngIf="item.activo">{{ item.nombre }}</li>
</ng-container>

Directivas y Pipes
Las directivas modifican el comportamiento del DOM. Los pipes transforman valores en el template. Ambos son reutilizables.
🎨 Directiva de Atributo Personalizada @Directive
Angular

Modifican comportamiento/apariencia de un elemento sin crear uno nuevo. @HostListener escucha eventos del elemento host. @HostBinding enlaza propiedades.

import { Directive, ElementRef, HostListener,
         HostBinding, Input } from '@angular/core';

@Directive({
  selector: '[appResalta]',  // se aplica como atributo
  standalone: true,
})
export class ResaltaDirective {
  @Input() appResalta = 'yellow';  // color como input

  // @HostBinding enlaza una propiedad del elemento
  @HostBinding('style.backgroundColor') bgColor = '';

  @HostListener('mouseenter') onEnter() {
    this.bgColor = this.appResalta;
  }
  @HostListener('mouseleave') onLeave() {
    this.bgColor = '';
  }
}

<!-- Uso -->
<p [appResalta]="'cyan'">Hover sobre mí</p>
<p appResalta>Usa color por defecto</p>
🔧 Pipes — Built-in y Personalizados @Pipe
Angular 
<!-- PIPES INTEGRADOS -->
{{ nombre | uppercase }}           <!-- CARLOS -->
{{ nombre | lowercase }}           <!-- carlos -->
{{ nombre | titlecase }}           <!-- Carlos García -->
{{ texto  | slice:0:100 }}         <!-- primeros 100 chars -->
{{ 1234.5 | number:'1.2-2' }}      <!-- 1,234.50 -->
{{ precio | currency:'USD':'symbol':'1.2-2' }} <!-- $12.00 -->
{{ 0.75   | percent }}             <!-- 75% -->
{{ hoy    | date:'dd/MM/yyyy' }}   <!-- 16/06/2025 -->
{{ hoy    | date:'medium' }}       <!-- Jun 16, 2025 -->
{{ objeto | json }}                <!-- debug: imprime JSON -->
{{ items  | keyvalue }}            <!-- itera objeto como {key,value} -->
{{ data$  | async }}               <!-- auto-subscribe a Observable -->

// PIPE PERSONALIZADO
@Pipe({ name: 'truncate', standalone: true, pure: true })
export class TruncatePipe implements PipeTransform {
  transform(v: string, limit = 50, suffix = '...'): string {
    return v.length <= limit ? v : v.slice(0, limit) + suffix;
  }
}
// Uso: {{ descripcion | truncate:100:'…' }}

// pure: true  → solo recalcula si el input cambia (default) ✅
// pure: false → recalcula en cada detección de cambios (costoso)

Comunicación entre Componentes
Padre a hijo con @Input, hijo a padre con @Output/EventEmitter. Y las formas funcionales modernas: input() y output().
📡 @Input / @Output — Clásico y Moderno Comunicación
Angular 
// ── HIJO — recibe y emite ─────────────────────────────────────
import { Component, Input, Output, EventEmitter,
         input, output, model } from '@angular/core';

@Component({ selector: 'app-tarjeta', standalone: true, template: `
  <h3>{{ titulo }}</h3>
  <p>Edad: {{ edad() }}</p>
  <button (click)="eliminar()">Eliminar</button>
  <input [(ngModel)]="seleccionado" />   <!-- model() = two-way -->
` })
export class TarjetaComponent {
  // Forma CLÁSICA (decorador)
  @Input({ required: true }) titulo!: string;   // requerido
  @Input() color = 'blue';                        // con default
  @Output() deleted = new EventEmitter<void>();

  // Forma MODERNA funcional (Angular 17+) — son Signals
  edad         = input<number>(0);           // input signal (read-only)
  edadReq      = input.required<string>();    // input requerido
  onDelete     = output<string>();             // output signal
  seleccionado = model('');                   // two-way (v17.1+)

  eliminar() {
    this.deleted.emit();         // forma clásica
    this.onDelete.emit('ok');   // forma moderna
  }
}

// ── PADRE — pasa y escucha ────────────────────────────────────
<!-- [propiedad] = pasar valor | (evento) = escuchar -->
<app-tarjeta
  titulo="Mi tarjeta"
  [color]="colorActual"
  [edad]="25"
  (deleted)="onDelete()"
  (onDelete)="handleDelete($event)"
  [(seleccionado)]="valorPadre">
</app-tarjeta>

Servicios e Inyección de Dependencias
Los servicios centralizan la lógica compartida. Angular los crea una sola vez (singleton) y los inyecta donde se necesiten.
💉 @Injectable e inject() DI
Angular 
@Injectable({
  providedIn: 'root'  // singleton global (recomendado)
  // 'platform'  → compartido entre apps en la misma página
  // 'any'       → instancia por módulo lazy
  // providers en @Component → instancia por componente
})
export class UsuarioService {
  private usuarios = signal<Usuario[]>([]);
  usuariosPublico = this.usuarios.asReadonly();

  agregar(u: Usuario) {
    this.usuarios.update(lista => [...lista, u]);
  }
}

// ── Consumir el servicio ──────────────────────────

// Forma MODERNA — inject() (recomendada Angular 14+)
export class MiComponent {
  private usuarioSrv = inject(UsuarioService);
  private router     = inject(Router);
}

// Forma CLÁSICA — constructor (sigue siendo válida)
constructor(private usuarioSrv: UsuarioService) {}
🏭 InjectionToken y Proveedores Advanced DI
Angular

Para inyectar valores que no son clases: strings, objetos de configuración, funciones factory.

import { InjectionToken, inject } from '@angular/core';

// Definir el token tipado
const API_URL = new InjectionToken<string>('ApiUrl');

// app.config.ts — registrar el valor
providers: [
  { provide: API_URL, useValue: 'https://api.ejemplo.com' },

  // useClass   → provee una clase alternativa/mock
  { provide: Logger, useClass: FileLogger },

  // useFactory → función que crea el valor
  { provide: CONFIG, useFactory: () => ({ debug: false }) },

  // useExisting → alias de otro provider ya registrado
  { provide: AbstractLogger, useExisting: Logger },
]

// Consumir el token
export class ApiService {
  private url = inject(API_URL);
}

Routing y Navegación
El Router de Angular permite construir SPAs con múltiples vistas. Lazy loading, rutas hijas, parámetros y navegación programática.
🗺️ Definición de Rutas app.routes.ts
Angular 
// app.routes.ts
export const routes: Routes = [
  // Redirección por defecto
  { path: '', redirectTo: '/home', pathMatch: 'full' },

  // Ruta simple
  { path: 'home', component: HomeComponent },

  // Con parámetro de ruta (:id)
  { path: 'usuario/:id', component: UserDetailComponent },

  // Lazy loading ← SIEMPRE preferir esto
  {
    path: 'dashboard',
    loadComponent: () =>
      import('./features/dashboard/dashboard.component')
        .then(m => m.DashboardComponent),
  },

  // Lazy loading de un módulo de rutas hijas
  {
    path: 'admin',
    loadChildren: () =>
      import('./features/admin/admin.routes')
        .then(m => m.adminRoutes),
  },

  // Ruta comodín — 404
  { path: '**', component: NotFoundComponent },
];

// main.ts — registrar el router
bootstrapApplication(AppComponent, {
  providers: [provideRouter(routes,
    withComponentInputBinding(),   // params → @Input
    withHashLocation(),             // usa # en la URL
    withPreloading(PreloadAllModules) // precarga lazy
  )]
});

// En TypeScript
export class UserDetail {
  private router = inject(Router);
  private route  = inject(ActivatedRoute);

  ngOnInit() {
    // Leer params (snapshot = una sola vez)
    const id = this.route.snapshot.params['id'];

    // Observable (cuando el param cambia sin recargar)
    this.route.params.subscribe(p => console.log(p['id']));

    // Query params
    this.route.queryParams.subscribe(q => console.log(q['q']));
  }

  irAHome()        { this.router.navigate(['/home']); }
  irAUsuario(id: number) { this.router.navigate(['/usuario', id]); }
  atras()          { inject(Location).back(); }
}

Formularios
Dos enfoques: Template-Driven (simples, declarativos) y Reactive Forms (potentes, basados en código). Para validación avanzada siempre usa Reactive.
📋 Template-Driven Forms FormsModule
Angular

Ideales para formularios pequeños. La lógica vive en el HTML con ngModel.

// Importar FormsModule en el componente standalone
@Component({ imports: [FormsModule, NgIf], ... })
export class LoginComponent {
  email    = '';
  password = '';

  onSubmit(form: NgForm) {
    if (form.valid) console.log(form.value);
  }
}

<!-- Template -->
<form #loginForm="ngForm" (ngSubmit)="onSubmit(loginForm)">

  <input
    name="email"
    [(ngModel)]="email"
    required
    email
    #emailField="ngModel"
  />
  <p *ngIf="emailField.invalid && emailField.touched">
    Email inválido
  </p>

  <input
    name="password"
    type="password"
    [(ngModel)]="password"
    required
    minlength="8"
  />

  <button [disabled]="loginForm.invalid">Entrar</button>
</form>

// Estados del control: pristine, dirty, touched, untouched, valid, invalid
⚡ Reactive Forms ReactiveFormsModule
Angular

La lógica está en el TypeScript. Más potentes y testables. Ideales para formularios complejos.

@Component({ imports: [ReactiveFormsModule, NgIf], ... })
export class RegisterComponent {

@Injectable({ providedIn: 'root' })
export class ProductoService {
  private http = inject(HttpClient);
  private url  = `${environment.apiUrl}/productos`;

  // GET — lista
  getAll()  { return this.http.get<Producto[]>(this.url); }

  // GET — con query params  /productos?q=café&page=2
  buscar(q: string, page = 1) {
    const params = new HttpParams().set('q', q).set('page', page);
    return this.http.get<Producto[]>(this.url, { params });
  }

  // POST — crear
  crear(p: Omit<Producto, 'id'>) {
    return this.http.post<Producto>(this.url, p);
  }

  // PUT — reemplazar completo
  actualizar(id: number, p: Producto) {
    return this.http.put<Producto>(`${this.url}/${id}`, p);
  }

  // PATCH — actualizar parcialmente
  patchear(id: number, datos: Partial<Producto>) {
    return this.http.patch<Producto>(`${this.url}/${id}`, datos);
  }

  // DELETE
  eliminar(id: number) {
    return this.http.delete(`${this.url}/${id}`);
  }

  // Acceder a headers/status de la respuesta
  getConCabeceras() {
    return this.http.get<Producto[]>(this.url, { observe: 'response' });
    // .status, .headers, .body accesibles
  }
}

import { of, from, interval, Subject, BehaviorSubject } from 'rxjs';
import {
  map, filter, tap, take, scan, startWith,
  debounceTime, distinctUntilChanged, throttleTime,
  switchMap, mergeMap, concatMap, exhaustMap,
  catchError, retry, finalize,
  combineLatest, forkJoin, withLatestFrom,
  takeUntil, takeUntilDestroyed, shareReplay,
} from 'rxjs/operators';

// ── TRANSFORMACIÓN ───────────────────────────────────
obs$.pipe(
  map(x => x * 2),              // transforma cada valor
  filter(x => x > 0),           // filtra valores
  tap(x => console.log(x)),     // efecto sin modificar
  take(5),                        // toma solo 5
  startWith(0),                  // emite valor inicial
  scan((acc, v) => acc + v, 0),  // acumulador (como reduce)
);

// ── BÚSQUEDA EN TIEMPO REAL (patrón clásico) ─────────
inputCambio$.pipe(
  debounceTime(300),            // espera 300ms de silencio
  distinctUntilChanged(),        // ignora si el valor no cambió
  switchMap(q => api.buscar(q)) // cancela petición anterior ✅
);

// ── OPERADORES DE APLANAMIENTO ────────────────────────
// switchMap  → cancela anterior (búsquedas, autocompletado)
// mergeMap   → en paralelo, no cancela (subidas de archivos)
// concatMap  → en secuencia, uno a uno (guardar en orden)
// exhaustMap → ignora nuevos mientras el actual activo (login)

// ── COMBINACIÓN ─────────────────────────────────────
combineLatest([user$, config$])
  .subscribe(([user, config]) => { ... }); // emite cuando cualquiera cambia

forkJoin([api.getA(), api.getB()])
  .subscribe(([a, b]) => { ... });          // espera que TODOS completen

// ── MANEJO DE ERRORES ────────────────────────────────
api$.pipe(
  retry(3),                                    // reintenta 3 veces
  catchError(err => of({ error: err.message })), // recupera con valor
  finalize(() => loading.set(false))            // siempre se ejecuta
);

// ── SUBJECTS ─────────────────────────────────────────
const s  = new Subject<string>();         // no guarda último valor
const bs = new BehaviorSubject('init');   // guarda y emite el último ✅
s.next('valor');
bs.getValue();                             // valor actual síncrono

// ── EVITAR MEMORY LEAKS ─────────────────────────────
// ① takeUntilDestroyed (Angular 16+) — en constructor
private destroyRef = inject(DestroyRef);
stream$.pipe(takeUntilDestroyed(this.destroyRef)).subscribe(...);

// ② AsyncPipe en template (auto-unsubscribe)
// {{ stream$ | async }}

import { signal, computed, effect } from '@angular/core';

export class CarritoComponent {
  // signal → valor primitivo reactivo writable
  count   = signal(0);
  precio  = signal(19.99);
  nombre  = signal('Angular');

  // computed → derivado de otros signals (read-only)
  total   = computed(() => this.count() * this.precio());
  resumen = computed(() => `${this.nombre()}: $${this.total().toFixed(2)}`);

  constructor() {
    // effect → efecto secundario cuando un signal cambia
    effect(() => {
      console.log('Total actualizado:', this.total());
      // se re-ejecuta cada vez que total() (o sus deps) cambian
    });
  }

  // Formas de actualizar un signal
  setCount(n: number)   { this.count.set(n); }        // set valor
  increment()            { this.count.update(v => v + 1); } // update fn
  publicarSolo()         { return this.count.asReadonly(); } // read-only
}

// interceptors/auth.interceptor.ts
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(AuthService).getToken();

  const newReq = token
    ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } })
    : req;

  return next(newReq);  // pasa al siguiente interceptor o al servidor
};

// interceptors/error.interceptor.ts
export const errorInterceptor: HttpInterceptorFn = (req, next) =>
  next(req).pipe(
    catchError((err: HttpErrorResponse) => {
      const router = inject(Router);
      if (err.status === 401) router.navigate(['/login']);
      if (err.status === 403) router.navigate(['/forbidden']);
      if (err.status === 500) inject(ToastService).error('Error del servidor');
      return throwError(() => err);
    })
  );

export const loadingInterceptor: HttpInterceptorFn = (req, next) => {

// features/productos/store/productos.store.ts
import { Injectable, signal, computed, inject } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class ProductosStore {
  private http = inject(HttpClient);

  // ── Estado privado (solo el store puede modificarlo) ──
  private _productos = signal<Producto[]>([]);
  private _loading   = signal(false);
  private _error     = signal<string | null>(null);
  private _filtro    = signal('');

  // ── Selectores públicos (read-only) ──────────────────
  productos = this._productos.asReadonly();
  loading   = this._loading.asReadonly();
  error     = this._error.asReadonly();

  // Selectores derivados (computed)
  filtrados = computed(() =>
    this._productos().filter(p =>
      p.nombre.toLowerCase().includes(this._filtro().toLowerCase())
    )
  );
  total = computed(() => this._productos().length);

  // ── Acciones ─────────────────────────────────────────
  setFiltro(q: string) { this._filtro.set(q); }

  async cargar() {
    this._loading.set(true);
    this._error.set(null);
    try {
      const data = await firstValueFrom(
        this.http.get<Producto[]>('/api/productos')
      );
      this._productos.set(data);
    } catch(e: any) {
      this._error.set(e.message);
    } finally {
      this._loading.set(false);
    }
  }

  agregar(p: Producto) {
    this._productos.update(lista => [...lista, p]);
  }

  eliminar(id: number) {
    this._productos.update(lista => lista.filter(p => p.id !== id));
  }
}

// En cualquier componente
export class ListaComponent {
  store = inject(ProductosStore);

  ngOnInit() { this.store.cargar(); }
}
