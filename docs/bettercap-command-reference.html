KALI LINUX · bettercap 2.41.x

bettercap command reference

A single-page reference to every interactive-session command bettercap ships, organized by module. Built for offline use on an isolated lab network — no external fonts, scripts, or trackers.

About the version number

On Kali, the string v1.3.0 belongs to the bettercap-ui package (the Angular web UI bundle), not the bettercap engine itself. The engine — the part that owns every command on this page — is versioned separately and currently sits at 2.41.x (checked against the Kali tool pages and the upstream bettercap/bettercap releases). Run bettercap -version in your VM to confirm what you actually have installed; everything below is written against the 2.41 command set.

This is also why the "new" commands you noticed exist: recent 2.x releases added the entire CAN‑bus module family, the zerogod mDNS/Bonjour impersonation module, the ssh.proxy MITM proxy, a scriptable dns.proxy, the c2 IRC command‑and‑control module, and record/replay support for api.rest. They're all covered here.

Lab-use reminder

Every module here performs active reconnaissance, spoofing, or interception. Only point it at interfaces, networks, and VMs you own or have explicit written authorization to test — this build is for an isolated lab, and it should stay that way.

Launching & CLI flags

Flags passed to the bettercap binary itself, before the interactive session starts.

FlagPurpose
-iface IFACENetwork interface to bind to (name, IP, or MAC). Auto-detected if omitted.
-caplet FILELoad and run a .cap script file in the session.
-caplets-path PATHAlternative base path to search for caplets.
-eval "CMDS"Run one or more ;-separated commands on startup — handy for one-liners.
-script FILELoad a JS session script (see the Scripting docs).
-autostart MODULESComma-separated modules to auto-start (defaults to events.stream).
-gateway-override ADDRUse this IP as the gateway instead of the auto-detected one.
-no-historyDisable the ~/.bettercap.history file.
-no-colorsDisable terminal colors/effects.
-env-file FILEPreload parameters from this file (default ~/bettercap.env); empty string disables persistence.
-silentSuppress all non-error logs.
-debugEnable debug logging.
-versionPrint version/build info and exit.
Terminal — update caplets then quit 
sudo bettercap -eval "caplets.update; q"

Core session commands

Available in every session regardless of which modules are loaded. Chain commands with ; on one line.

helpList every command, and show each module's running/not-running status.
help MODULEShow the help menu for one module only.
activeShow which modules are currently running, with their parameters.
quit / qClose the session.
sleep SECONDSPause for N seconds (useful inside caplets/tickers).
get PARAMPrint a parameter's value; get * dumps everything.
set PARAM VALUESet a parameter; set PARAM "" clears it.
read PARAM "PROMPT"Interactively ask the user for a value and store it in PARAM.
clearClear the terminal.
include CAPLETLoad and run a caplet in the current session.
!COMMANDRun a shell command and print its output into the session.
alias MAC NAMEGive an endpoint a friendly, persistent name (saved to ~/bettercap.aliases).
Terminal — scripted example 
set arp.spoof.targets 192.168.1.20; arp.spoof on
help net.recon; q                         # man-page style: show help then exit
read arp.spoof.targets "Target to spoof: "

Core modules

caplets

Lists and updates installed caplets — scripted .cap session files, bettercap's equivalent of Metasploit .rc resource scripts.

caplets.showList installed caplets.
caplets.pathsList the search paths used to find caplets.
caplets.updateInstall/update the official caplet collection.

events.stream

On by default. Reports every event other modules generate (new hosts, captured handshakes, log lines…) and can run commands in response to them.

events.stream on / offStart or stop the stream.
events.show LIMITPrint buffered events (optionally the last N).
events.ignore FILTERHide events whose tag matches FILTER (stackable).
events.include FILTERRemove a previously added ignore filter.
events.filters / events.filters.clearList / clear active ignore filters.
events.clearEmpty the events buffer.
events.waitfor TAG TIMEOUTBlock until an event with TAG fires (optional timeout, seconds).
events.on TAG COMMANDSRegister a trigger: run COMMANDS whenever TAG fires. Supports {{Field}} payload placeholders.
events.triggers / events.triggers.clearList / clear all triggers.
events.trigger.delete IDRemove one trigger by id.
Parameters
events.stream.outputWrite events to this file instead of stdout.
events.stream.output.rotate*Log rotation by size or time, with optional gzip compression.
events.stream.http.request.dumpfalseDump full HTTP request bodies.
events.stream.http.response.dumpfalseDump full HTTP response bodies.
events.stream.time.format15:04:05Go time-format string for event timestamps.
Terminal — auto-deauth a new client, auto-assoc a new AP 
events.on wifi.client.new wifi.deauth {{Client/mac}}
events.on wifi.ap.new wifi.assoc {{mac}}

Builds a connectivity graph of discovered WiFi and LAN nodes and exports it.

graph.to_dot MACExport a Graphviz .dot file (optionally filtered to one MAC).
graph.to_json MACExport JSON instead.
Parameters
graph.privacyfalseObfuscate MAC addresses in exports.
graph.disconnectedfalseInclude disconnected edges.
graph.dot.layout / .name / .outputneato / bettergraph / bettergraph.dotGraphviz export settings.

ticker

Runs a set of commands on a repeating interval — the engine behind most "live dashboard" caplets.

ticker on / offStart/stop the main ticker.
ticker.create NAME PERIOD "CMDS"Create and start a named ticker running CMDS every PERIOD seconds.
ticker.destroy NAMEStop a named ticker.
Parameters
ticker.period1Seconds between main-ticker runs.
ticker.commandsclear; net.show; events.show 20Commands the main ticker executes.
Terminal — redeauth a BSSID every 5 seconds 
set ticker.period 5
set ticker.commands "wifi.deauth DE:AD:BE:EF:DE:AD"
ticker on
# or, as a named ticker that doesn't block the main one:
ticker.create deauthenticator 5 "wifi.deauth DE:AD:BE:EF:DE:AD"

api.rest automation

A RESTful API over the live session — read state, post commands, and now record/replay whole sessions. Unauthenticated HTTP by default.

api.rest on / offStart/stop the API server.
api.rest.record FILEPoll the API on a timer and record samples to a compressed file.
api.rest.record offStop recording.
api.rest.replay FILEReplay a recorded session through the API instead of live data.
api.rest.replay offReturn to live mode.
Parameters
api.rest.address / .port127.0.0.1 / 8081Bind address and port.
api.rest.username / .passworduser / passHTTP basic-auth credentials.
api.rest.certificate / .keyFill both to switch the API to HTTPS (auto-generated if missing).
api.rest.websocketfalseServe /api/events as a websocket instead of plain HTTP.
api.rest.alloworigin*CORS Access-Control-Allow-Origin value.
api.rest.record.clock1Seconds between samples while recording.

Key routes: GET /api/session, GET /api/session/lan, GET /api/session/wifi, GET /api/session/ble, GET /api/session/hid, GET /api/events, DELETE /api/events, POST /api/session (body {"cmd":"net.probe on"}), GET /api/file?name=FILE.

c2.channel.clear TAGRemove that routing.
c2.template.set TAG TEMPLATECustomize the report format for events tagged TAG.
c2.template.clear TAGReset to the default template.
Parameters
c2.serverlocalhost:6697IRC server:port.
c2.server.tls / .tls.verifytrue / falseTLS on by default; cert validation off by default.
c2.nick / .username / .passwordbettercap / bettercap / passwordIRC identity.

wifi.bruteforce on / offWordlist-based WiFi auth bruteforce.

wifi.bruteforce.wordlist / .target / .workers / .timeout / .wide / .stop_at_first/usr/share/dict/words · — · 1 · 15 · false · trueBruteforce tuning — keep workers low, routers ban fast.

Spoofers (MITM)

Spoofers redirect traffic through this host; pair them with a proxy below to actually read or modify what passes through.

arp.spoof

The classic ARPv4 MITM — poisons target ARP caches with crafted replies.

arp.spoof onStart spoofing.
arp.ban onSpoof in "ban" mode — the target loses connectivity entirely.
arp.spoof off / arp.ban offStop and restore ARP caches (unless skip_restore is set).
Parameters
arp.spoof.targets<entire subnet>MACs / IPs / ranges / aliases to spoof.
arp.spoof.spoofed<gateway>Addresses to impersonate — defaults to the gateway.
arp.spoof.whitelistAddresses to never touch.
arp.spoof.fullduplexfalseAlso poison the gateway, not just the target (fails against routers with ARP-spoof protection).
arp.spoof.internalfalseAlso spoof purely local-to-local traffic.
arp.spoof.forwardingtrueKeep IP forwarding on while spoofing (off = pure traffic analysis, no relay).
arp.spoof.interval1000ms between spoofed broadcasts.
arp.spoof.skip_restorefalseDon't restore target ARP caches on stop.
Terminal 
set arp.spoof.targets 192.168.1.2-4; arp.spoof on

dhcp6.spoof

The mitm6-style attack: replies to Windows hosts' DHCPv6 solicitations with a link-local IPv6 address and sets this host as their DNS server. Pair with dns.spoof to actually be useful.

dhcp6.spoof on / offStart/stop the DHCPv6 spoofer.
Parameters
dhcp6.spoof.domainsmicrosoft.com, google.com, facebook.com, apple.com, twitter.comDomains to target.

dns.spoof

Answers DNS queries with forged responses. Needs arp.spoof or dhcp6.spoof running first to actually receive the queries.

dns.spoof on / offStart/stop.
Parameters
dns.spoof.domainsComma-separated domains to spoof.
dns.spoof.address<iface address>IP to resolve matched domains to.
dns.spoof.allfalseAnswer every request seen, not just ones addressed to this host.
dns.spoof.hostsUse a hosts-file for many mappings instead of domains/address.
dns.spoof.ttl1024TTL on spoofed replies.
Terminal 
set dns.spoof.domains example.com
set dns.spoof.address 1.2.3.4
dns.spoof on

ndp.spoof

IPv6 neighbor spoofing via crafted Neighbor/Router Advertisements — the IPv6 analogue of ARP spoofing.

ndp.spoof onStart spoofing.
ndp.ban onBan mode — target loses connectivity.
ndp.spoof off / ndp.ban offStop.
Parameters
ndp.spoof.targetsIPv6 victim addresses.
ndp.spoof.neighbourfe80::1Address to spoof in Neighbor Advertisements; clear to disable NAs.
ndp.spoof.prefix / .prefix.lengthd00d:: / 64Router-advertisement prefix; clear the prefix to disable RAs.

Proxies

Scripting any of the http/https/dns/tcp/ssh proxies

Each one loads an optional JS file (its *.script or *.hostkey-style parameter) implementing hooks like onLoad(), onRequest(req,res) / onResponse(req,res) (HTTP/HTTPS/DNS), onData(from,to,data) (TCP), or onSSHData(sessionID,direction,data) (SSH) — the interpreter is ES5-only (no for/of, typed arrays, or classes). Builtins available inside every script: readFile, writeFile, readDir, fileExists, log()/log_warn()/log_error(), btoa/atob, gzipCompress/gzipDecompress, env() (get/set session vars), run("shell cmd"), loadJSON/saveJSON, and onEvent/removeEventListener/addSessionEvent for hooking the session's own event bus from JS.

any.proxy

A plain firewall redirection to any external proxy you already run (Burp, mitmproxy, etc) — no bettercap-side logic, just traffic steering.

any.proxy on / offStart/stop the redirection.
Parameters
any.proxy.protocolTCPTCP or UDP.
any.proxy.src_port / .src_address80 / anyWhat to intercept.
any.proxy.dst_address / .dst_port<iface addr> / 8080Where your external proxy listens.
any.proxy.iface<iface name>Interface to redirect from.
Terminal — send HTTP to a local Burp instance 
set any.proxy.dst_address 127.0.0.1
any.proxy on

Parameters

https.port443Port redirected into the proxy.
https.proxy.certificate / .key~/.bettercap-ca.*.pemThe forging CA's cert/key (auto-generated).

packet.proxy Linux only

NFQUEUE-based raw packet filtering through compiled Go plugins — the lowest-level, highest-effort hook point, for custom filtering logic that JS can't express efficiently.

ssh.proxy new

An SSH MITM proxy: presents its own host key to the client, captures password and public-key auth attempts in the clear, logs session I/O, and forwards transparently to the real server.

ssh.proxy on / offStart/stop.
Parameters
ssh.proxy.port / .address2222 / <iface addr>Bind settings.
ssh.port22Remote SSH port intercepted.
ssh.addressReal destination. Leave empty to auto-detect per-connection (Linux: SO_ORIGINAL_DST; macOS: pf state table).
ssh.proxy.hostkeyPEM private key to present; auto-generated (ephemeral ECDSA P-256) if empty.
ssh.proxy.scriptJS hook file (onSSHData).
Terminal — full-duplex ARP spoof + SSH MITM for the whole LAN 
set arp.spoof.fullduplex true
set ssh.port       22
set ssh.proxy.port 2222
ssh.proxy on
arp.spoof on

A ready-made sshproxy.cap caplet ships with bettercap and chains every spoofer and proxy above into one full IPv4+IPv6 MITM run.
